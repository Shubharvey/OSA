# OSA — One Step Ahead

A personalised global intelligence platform that simplifies markets, emerging technologies, startups and career opportunities.

## Product direction

OSA brings useful global signals into one focused, source-attributed intelligence feed. The first milestone is a responsive dashboard with category navigation, filters and intelligence cards. The intelligence pipeline and personalisation layer will follow once the product experience is established.

## Initial stack

- Next.js + TypeScript
- Tailwind CSS
- Supabase
- GitHub
- Vercel

## MVP areas

- Markets
- Startups
- Technology
- Career
- Learning

## Development

The repository is the source of truth. Keep changes small, reviewable and documented. Never commit secrets; use environment variables for Supabase credentials.

## Status

Early MVP foundation — dashboard and data integration in progress.
